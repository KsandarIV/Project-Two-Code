---
name: zb-card
description: Start a ZibaldOne card: read it, plan the change, name the branch. Use on 'start card', a Trello link, or a new card thread.
---

1. Read the card and its comments.
2. Read the code map (if present); list the modules to touch.
3. Write: goal, acceptance criteria (5 at most), files, risks.
4. Propose the branch name `<type>/<card#>-<slug>`.
5. If the card mixes a capability and a fix, ask the coordinator to split it.
