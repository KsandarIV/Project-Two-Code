## Scelte
- Esiste già «Hexis» (`abitudine` in Delfi · Io, frequenza a testo libero): non si tocca. Nuovo pacchetto **`askesis`** («Askesis · Abitudini», 1.0.0), due modelli, area scelta per voce (di base Salute):
  - `rituale` (soprannome *Askesis*): `nome` text obbligatorio, `ogni` choice «Ogni giorno» / «Più volte a settimana», `volte` number (traguardo a settimana, solo con «Più volte»; 1–7, di base 3), `unita` text (es. «bicchieri», «minuti»; vuoto = fatto sì/no), `traguardo` number (quantità del giorno che conta come fatto, vuoto = basta segnare), `promemoria` choice «Sì»/«No» (di base No), `attivo` choice «Sì»/«No».
  - `pratica` (*Praxis*): `rituale` link→`rituale` (uno solo, obbligatorio), `quantita` number (facoltativa). Il giorno della voce (`entry.day`) è il giorno segnato. Al più una pratica per rituale e giorno.
- Riuso di `core/stats.streaks(days, today)` per le serie di giorni. Niente cifratura (le abitudini non sono sensibili).
- Tono (ADR-0008): mai frasi allarmanti, solo osservazioni neutre.

## Backend: `core/habits.py`, `packs/askesis.zbpack.json`, `cli/habit_cmd.py`, test
```
@dataclass(frozen=True) Habit: id, name, area, every ('day'|'week'), times (int, 1 se day), unit (str), goal (Decimal|None), reminder (bool), active (bool)
@dataclass(frozen=True) Streak: current (int), longest (int), done_this_week (int), target_week (int), done_today (bool)
load_habits(store, include_inactive=False) -> list[Habit]
practices_of(store, habit_id) -> dict[date, Decimal|None]     # giorno -> quantità
streak(habit, practices, today) -> Streak
    # day: giorni di fila con una pratica (che raggiunge `goal` se c'è); oggi non ancora segnato NON spezza la serie
    # week: la serie conta settimane (lun-dom) consecutive con almeno `times` pratiche
due_today(habits, practices_by_habit, today) -> list[Habit]   # attivi, non ancora fatti oggi
mark(store, habit_id, day, quantity=None) -> Entry            # crea o aggiorna la pratica del giorno (una sola); non nel futuro
unmark(store, habit_id, day) -> bool                          # toglie la pratica; False se non c'era
class HabitError(ValueError)                                  # messaggi in italiano: «manca il modello …», «giorno nel futuro», «quantità non valida»
```
CLI: `zbone abitudini` (oggi: da fare e serie), `abitudini segna NOME [QUANTITÀ] [--giorno AAAA-MM-GG]`, `abitudini togli NOME [--giorno]`, `abitudini serie`. NOME può essere le prime lettere; ambiguo = errore con elenco.
Test: serie con giorno saltato, oggi non segnato, settimana con `times`, quantità sotto traguardo, doppia pratica, giorno futuro.
Backend NON modifica `ui/`. `UPCOMING` in `core/areas.py` è di Sviluppo (lo tolgo io con la versione; avverto Backend).
