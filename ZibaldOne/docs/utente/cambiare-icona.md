# Cambiare l'icona di ZibaldOne su Windows

ZibaldOne ha quattro icone: **A** (ruota con anello), **B** (ruota con spicchi staccati), **C** (monogramma ZO, quella predefinita) e **D** (tessere). Il file `.ico` di ognuna è nella cartella `docs/brand/icona/scelta/<lettera>/` e si chiama `icona.ico`. Se hai scaricato l'app dalle Releases, i quattro file sono nello zip, nella cartella `icone`.

L'icona del file `ZibaldOne.exe` non si cambia. Si cambia quella del **collegamento**, che è quello che vedi sul desktop e nel menu Start.

## Passo per passo
1. Copia la cartella `icone` in un posto che non sposti più, per esempio `Documenti\ZibaldOne\icone`. Se sposti o cancelli il file, il collegamento torna senza icona.
2. Se non hai un collegamento: clic destro su `ZibaldOne.exe`, poi **Mostra altre opzioni**, **Invia a**, **Desktop (crea collegamento)**.
3. Clic destro sul collegamento, poi **Proprietà**.
4. Nella scheda **Collegamento** premi **Cambia icona…**. Se compare un avviso, premi **OK**.
5. Premi **Sfoglia…**, vai nella cartella dei passi 1 e scegli il file `icona.ico` della lettera che ti piace.
6. Premi **OK** due volte. L'icona cambia subito; se resta quella vecchia, riavvia Esplora risorse o disconnetti e riconnetti la sessione.

## Nel menu Start e nella barra delle applicazioni
- Per il menu Start: clic destro sul collegamento, **Aggiungi a Start**. Per la barra: **Aggiungi alla barra delle applicazioni**. Se l'hai già aggiunto, toglilo e aggiungilo di nuovo dopo il cambio.
- Quando l'app è aperta, la barra può mostrare comunque l'icona del programma e non quella del collegamento. Non è un errore.

## Tornare all'icona di prima
Stessi passi, e al passo 5 scegli `icona.ico` della cartella `C`.
