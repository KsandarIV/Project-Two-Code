# v0.2.4 — Media

- **Data**: 2026-10-17
- **Contiene**: il blocco **Allegati** per foto, video, audio e documenti delle voci e delle persone, salvati una volta sola sul dispositivo e copiati, cifrati, nei backup e nelle Nuvole ([gli allegati](../tecnica/allegati.md)).
- **Criteri di accettazione**
  - [x] Foto, video, audio e documenti si allegano alle voci (sera, pensiero, incontro) e alle persone, dall'app e dal terminale.
  - [x] Sono inclusi nei backup cifrati: ogni istantanea elenca i suoi file, la verifica li controlla, il ripristino li rimette.
  - [x] Vanno anche nelle copie fuori (Drive o cartella), cifrati, e tornano su un dispositivo nuovo.
  - [x] Un file allegato due volte occupa il posto di uno; quelli che nessuno usa più si cancellano, sul dispositivo, nei backup e fuori.
  - [x] Le voci scritte con Stoa 1.0.1 e Agorà 1.4.0 restano valide: i pacchetti si aggiornano.
- **Scelte**
  - I file stanno fuori dal database, con il nome della loro impronta SHA-256: il database resta piccolo e i backup non li ricopiano ogni giorno.
  - Le copie nei backup sono una per file, non una per istantanea; l'elenco dei file di un'istantanea è nella sua intestazione pubblica, così la pulizia funziona senza passphrase.
  - Massimo 100 MB per file.
- **Non ancora verificato**: sul telefono vero (provato nel browser alla larghezza di un telefono), in particolare la scelta dei file e il menu Condividi di Android.
- **Limiti noti**: video e audio si aprono con il programma del sistema, non nell'app; la ricerca non guarda i nomi dei file; sul dispositivo gli allegati sono in chiaro come il database.
- **Come provarla**: `zbone pack install diario`, poi `zbone allegati aggiungi ID foto.jpg`, `zbone allegati mostra ID`, `zbone backup create`; nell'app apri **Esame serale**, «Aggiungi file», salva e tocca la foto.
