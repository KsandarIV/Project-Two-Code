# v0.0.6 — Storia e backup

- **Data**: 2026-10-17
- **Contiene**: le istantanee dei dati come commit (Mnemosyne), il ripristino annullabile, la durata a tempo, la verifica, l'export in Markdown e CSV, la nuova numerazione delle versioni.
- **Criteri di accettazione**
  - [x] `backup create` salva un'istantanea coerente con nota; `backup list` le mostra dalla più recente.
  - [x] Dopo un comando che salva dati parte l'istantanea automatica, al massimo una ogni 24 ore; i comandi che leggono soltanto non la fanno partire.
  - [x] Prima di un aggiornamento dello schema del database c'è un'istantanea "prima di un aggiornamento".
  - [x] `backup restore` controlla l'istantanea, salva lo stato attuale e poi sostituisce il database; il ripristino si può annullare con l'id stampato.
  - [x] Consenso privacy, durata dei backup e chiavi non tornano indietro con un ripristino.
  - [x] `backup verify` trova un'istantanea rovinata.
  - [x] `backup prune` segue la durata (7/4/12 di base) e tiene sempre la più recente e l'ultima "prima di un ripristino".
  - [x] `export markdown` e `export csv` creano uno zip e avvisano che non è cifrato.
  - [x] Avviso privacy versione 2 con il rischio delle voci cancellate che restano nei backup.
  - [x] `pytest` passa (144 test).
- **Scelte**
  - Copie complete invece che incrementali: semplici e robuste finché il database è piccolo. Si potrà passare a istantanee incrementali più avanti (ADR-0006).
  - L'istantanea automatica parte da `open_store()` solo se il comando ha cambiato il database (`total_changes` di SQLite), così non serve ricordarsene in ogni comando.
  - Il codice della cifratura entra già qui perché le istantanee hanno un solo formato; i comandi per attivarla arrivano nella 0.0.7.
  - Nuova numerazione: la 1.0 sarà l'app davvero usabile ([ADR-0010](../decisioni/ADR-0010-numerazione-delle-versioni.md)).
- **Come provarla**: `zbone backup create --note prova`, aggiungi una voce, poi `zbone backup restore <id>` e `zbone entry list`. Dettagli in [storia e backup](../tecnica/backup.md).
