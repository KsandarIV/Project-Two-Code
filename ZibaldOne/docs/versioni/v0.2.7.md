# v0.2.7 — Abitudini

- **Data**: 2026-10-24
- **Contiene**: il pacchetto **Askesis · Abitudini**: rituali segnati un giorno alla volta, con serie di giorni o di settimane ([le abitudini](../tecnica/abitudini.md)). Riquadro in Oggi, schermata `/abitudini`, riga nella pagina dell'area, `zbone abitudini`.
- **Criteri di accettazione**
  - [x] Un rituale si crea, si segna e si toglie per un giorno, dall'app e dal terminale.
  - [x] La serie conta i giorni di fila; oggi non segnato non la spezza; con un traguardo conta solo chi lo raggiunge.
  - [x] «Più volte a settimana» conta le settimane con abbastanza pratiche.
  - [x] Nessuna frase che colpevolizza; Hexis non cambia.
- **Non ancora verificato**: sul telefono vero; il riquadro con molti rituali; i fusi orari a cavallo della mezzanotte.
- **Limiti noti**: il promemoria è solo registrato, non suona; niente grafico nel tempo; gli **obiettivi con avanzamento** slittano alla 0.2.8.
- **Come provarla**: `zbone pack install askesis`, `zbone abitudini segna acqua 8`, `zbone abitudini`; nell'app **Oggi** o **/abitudini**.
- **Lavoro di squadra**: Backend (core, pacchetto, CLI), Frontend (schermate), Sviluppo (versione, docs).
