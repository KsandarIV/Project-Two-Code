# v0.0.4 — Modelli pronti e identità

- **Data**: 2026-10-17
- **Contiene**: quattro pacchetti di modelli pronti, i comandi `zbone pack list/show/install`, i nomi filosofici, le mascotte, `zbone pensiero` e `zbone about`.
- **Pacchetti**
  - **Stoa · Diario**: Meditazione del mattino, Meriggio, Esame serale (umore, voto della giornata, obiettivi di domani), Eudaimonia (le 8 aree da 0 a 10), Pensiero, Hypomnemata (settimana), Lettera a Lucilio (mese), Almanacco (anno).
  - **Museion · Collezioni**: Biblioteca di Babele (libri), Caverna (film), Eterno ritorno (serie), Anima mundi (anime), Homo ludens (videogiochi), Alea (giochi da tavolo), Mens sana (sport), Armonia delle sfere (musica), Maschera (guardaroba).
  - **Delfi · Io**: Conosci te stesso, Arché, Confessioni, Conatus, Hexis.
  - **Agorà · Persone**: L'Altro (persona), Simposio (incontro, collegato alle persone).
- **Criteri di accettazione**
  - [x] `pack list` dice per ogni pacchetto se è installato.
  - [x] `pack install` mostra il piano e chiede conferma; `--yes` salta la domanda.
  - [x] Reinstallare lo stesso pacchetto non cambia nulla; una versione più nuova aggiorna i modelli.
  - [x] Un modello dell'utente con lo stesso nome tecnico resta com'è e il pacchetto si installa come copia.
  - [x] I pacchetti integrati sono validi e usano solo blocchi esistenti; le icone esistono in Flet.
  - [x] `pensiero` cambia ogni giorno; `about` elenca le 8 mascotte e i nomi.
  - [x] `pytest` passa (75 test).
- **Scelte**
  - I nomi tecnici (`sera`, `libro`) restano semplici per il terminale; i nomi filosofici sono quelli che vedi.
  - I pacchetti sono file JSON generati da `scripts/build_builtin_packs.py`, così si leggono e si modificano facilmente.
  - Le mascotte sono tutte tenute; quella principale si sceglie più avanti.
- **Come provarla**: `zbone pack install diario`, poi `zbone entry add sera`; `zbone pensiero`; `zbone about`.
