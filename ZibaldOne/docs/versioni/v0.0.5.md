# v0.0.5 — Pacchetti da condividere

- **Data**: 2026-10-17
- **Contiene**: `zbone pack export` e `zbone pack import`, il formato `.zbpack.json` ([ADR-0005](../decisioni/ADR-0005-pacchetti-di-modelli.md)), il watcher che fa commit e tag a ogni cambio di versione.
- **Criteri di accettazione**
  - [x] `pack export` salva i modelli scelti in un file `.zbpack.json`; le voci non ci finiscono mai, neanche l'origine dei modelli.
  - [x] `pack show FILE` mostra nome, autore, versione, licenza e modelli senza installare nulla.
  - [x] `pack import FILE` mostra il piano e chiede conferma; un modello con lo stesso nome tecnico diventa una copia.
  - [x] File troppo grandi, non JSON, di un formato sconosciuto o con campi sconosciuti sono rifiutati con un messaggio.
  - [x] Il watcher fa commit e tag quando la versione sale, e non fa nulla se scende o se il tag esiste già (test con una repo git temporanea).
  - [x] `pytest` passa (77 test).
- **Scelte**
  - Il pacchetto è un file JSON leggibile, senza codice, così si può aprire e controllare prima di importarlo.
  - Licenza di base CC-BY-4.0: chi riusa un tuo modello ti cita.
  - Il watcher controlla il file ogni 2 secondi e aspetta 3 secondi dopo l'ultima modifica, per non fare il commit a metà di un salvataggio. Non richiede librerie in più.
- **Come provarla**: `zbone pack export sera --author Alex`, poi `zbone pack show esame_serale.zbpack.json`. Per il watcher vedi [versionamento](../sviluppo/versionamento.md).
