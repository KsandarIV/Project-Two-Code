# v0.3.1 — Solo correzioni

- **Data**: 2026-10-25
- **Contiene**: la home torna a riquadri fissi in lista, riordinabili solo col trascinamento (la griglia 5×6 della 0.3.0 è in pausa); backup rifatto (automatico: oggi, 4 settimanali, 3 mensili, 3 annuali; o manuale), file `.zbbackup` per salvare e importare, backup trovato al primo avvio; Theoria · Viste diventa Lente, con spiegazione e nove esempi; l'intestazione di area con la mascotte nei Modelli; la spiegazione dei campi a un tocco; correzioni del gesto dei caroselli, delle bozze, di «Novità» e del tasto indietro.   - [x] `zibaldone.__version__` è 0.3.1 e la versione ha il suo file delle novità.

  - [ ] Salva in un file e importa da un file provati su un dispositivo pulito.
