# v0.0.9 — Promemoria (Daimon)

- **Data**: 2026-10-17
- **Contiene**: i promemoria che spronano a scrivere nei 3 momenti della giornata, i comandi `zbone remind …` e le attività pianificate di Windows ([ADR-0008](../decisioni/ADR-0008-notifiche.md)).
- **Criteri di accettazione**
  - [x] Al massimo un promemoria per momento al giorno; nessuno se la voce di quel momento è già scritta, nelle ore di silenzio, nei giorni non scelti o se è spento.
  - [x] Un controllo in ritardo, dentro la finestra, manda il promemoria una volta sola.
  - [x] Dopo 3 promemoria ignorati di fila l'app propone di diradarli e non li spegne da sola.
  - [x] Il testo della notifica non contiene mai dati delle voci.
  - [x] `zbone remind install` crea su Windows un'attività per momento; su altri sistemi mostra cosa farebbe e non crea nulla.
  - [x] Un'attività pianificata senza consenso privacy si ferma invece di aspettare una risposta, e non chiede l'accesso con Google.
  - [x] Senza desktop-notifier il promemoria compare nel terminale.
  - [x] `pytest` passa.
- **Scelte**
  - Il calcolo è una funzione pura (`core/reminders.py`): si prova con qualsiasi ora, senza aspettare.
  - Niente server di notifiche push: tutto avviene sul dispositivo.
  - Le notifiche vengono prima dell'interfaccia grafica, che le usa: per questo l'interfaccia è diventata la 0.1.0.
- **Da verificare**: le notifiche su Android, con la prima APK (0.1.1).
- **Come provarla**: `zbone remind status`, `zbone remind test`, poi su Windows `zbone remind install`.
