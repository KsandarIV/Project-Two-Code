# v0.3.3.1 — APK della 0.3.3

- **Data**: 2026-11-05
- **Contiene**: nessuna novità per chi usa l'app. La release 0.3.3 è uscita senza APK perché la build di Android non trovava un insieme di pacchetti compatibili (`flet-permission-handler` 1.0.4 richiede Flet 1.0.4, il progetto usa Flet 1.0.5). Ora `flet-permission-handler` è alla 1.0.5.
- **Criteri di accettazione**
  - [x] Tutti i test passano e `zibaldone.__version__` è 0.3.3.1.
  - [x] `pip` risolve Flet 1.0.5 con i quattro pacchetti `flet-*` (provato senza installare).
  - [ ] L'APK si costruisce nella release e si installa sul telefono.
- **Non ancora verificato**: la build dell'APK (si vede solo in Actions) e tutto ciò che riguarda il telefono, come per la 0.3.3.
- **Cosa cambia per chi aggiorna**: niente rispetto alla 0.3.3. Chi ha lo zip di Windows della 0.3.3 non ha bisogno di questa versione.
