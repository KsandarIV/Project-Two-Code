# v0.2.5 — Svago avanzato

- **Data**: 2026-10-17
- **Contiene**: i modelli di Museion tengono le date di inizio e fine, i mezzi voti, le recensioni con spoiler, i preferiti, la lista dei desideri e il tempo speso; e si riempiono dai file di Goodreads, Letterboxd, MyAnimeList e Steam ([svago avanzato](../tecnica/svago.md)).
- **Criteri di accettazione**
  - [x] Quando lo stato di un libro, film, serie, anime o gioco cambia, si scrivono da soli il giorno di inizio e quello di fine (e la fine si toglie se si riapre).
  - [x] Il voto può avere mezzo punto (`8,5`), nel modulo e da terminale; senza l'opzione resta intero.
  - [x] Una recensione può restare nascosta dietro un avviso di spoiler.
  - [x] I preferiti, la lista dei desideri e il tempo speso per raccolta stanno nelle Collezioni.
  - [x] Un file di Goodreads, Letterboxd, MyAnimeList o Steam diventa voci, con anteprima prima di scrivere; due volte lo stesso file non duplica niente.
  - [x] Le voci scritte con Museion 1.1.0 restano valide: il pacchetto si aggiorna.
- **Scelte**
  - I mezzi voti restano su 5 stelle: portare il massimo a 10 cambierebbe il significato dei voti già dati. Chi vuole l'8,5 su 10 cambia *Stelle* nell'editor.
  - Le date di un import sono quelle del file, mai «oggi»: per questo `add_entry` ha `stamp=False`.
  - Si importa solo da file scelto dall'utente, mai dalle API dei servizi.
- **Non ancora verificato**: sul telefono vero (scelta del file, dialoghi); con file reali esportati dai servizi (provato con file scritti seguendo i loro formati).
- **Limiti noti**: le date non si correggono a mano; l'import non aggiorna le voci già presenti né porta manga, liste e copertine; Steam si importa solo dal JSON dell'API (non ha un'esportazione); la ricerca e le esportazioni contengono le recensioni con spoiler.
- **Come provarla**: `zbone pack install collezioni`, poi `zbone importa goodreads FILE.csv --prova`; nell'app apri **Collezioni**, «Importa da un file», e una voce di un libro: tocca due volte una stella per il mezzo voto.
