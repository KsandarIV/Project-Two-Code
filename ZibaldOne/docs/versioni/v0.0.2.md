# v0.0.2 — Cartella dati e trasparenza

- **Data**: 2026-10-17
- **Contiene**: cartella dati per piattaforma, avviso privacy al primo avvio con consenso, comandi `zbone privacy` (con `accept` e `revoke`) e `zbone data path`, file `settings.json` con `schema_version`.
- **Criteri di accettazione**
  - [x] Al primo comando che usa i dati l'app mostra l'avviso e chiede "Continuare? (sì/no)"; accetta anche `s`, `si`, `y`, `yes`.
  - [x] Se l'utente rifiuta, non viene creato nulla e il comando esce con codice 1.
  - [x] Dopo il sì l'avviso non viene più mostrato, finché non cambia la versione dell'avviso (`NOTICE_VERSION`).
  - [x] `zbone privacy` mostra avviso, cartella, se esiste, numero di file, spazio usato e stato del consenso, anche prima del consenso e senza creare nulla.
  - [x] `zbone privacy revoke` revoca il consenso e lascia i file al loro posto.
  - [x] `zbone data path` stampa solo il percorso, utile negli script.
  - [x] `help` e `version` funzionano senza consenso.
  - [x] I test usano sempre una cartella temporanea (`ZIBALDONE_HOME`), mai quella vera.
  - [x] `pytest` passa (18 test).
- **Cartella dati**: Windows `%APPDATA%\ZibaldOne`; Linux `~/.local/share/zibaldone`; Android dalla v0.0.8 tramite Flet. La variabile `ZIBALDONE_HOME` la sostituisce.
- **Scelte**: l'avviso è in italiano (tester italiani, e la trasparenza va data nella lingua di chi legge); l'aiuto dei comandi resta in inglese come nella v0.0.1. Ogni comando che usa i dati chiama `ensure_consent()` all'inizio.
- **Come provarla**: vedi [setup su Windows](../sviluppo/setup-windows.md), poi `zbone data path` e `zbone privacy`.
